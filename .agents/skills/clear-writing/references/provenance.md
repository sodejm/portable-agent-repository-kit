# Provenance and maintenance

This is a repository-local, vendor-neutral synthesis of the user's clear-writing
workflow. It preserves its meaning-first approach without depending on a personal
skill directory or vendor-specific agent configuration. PARK's repository license
covers this original implementation; downstream projects must preserve applicable
license notices when copying it.

The guidance draws on these sources, summarized rather than reproduced:

- [Google developer documentation style guide](https://developers.google.com/style):
  reader-focused organization, clear technical language, active voice with
  exceptions, accessible structure and useful procedures.
- [George Orwell, Politics and the English Language](https://www.orwellfoundation.com/the-orwell-foundation/orwell/essays-and-other-works/politics-and-the-english-language/):
  avoid worn-out imagery, unnecessary words and needless complexity; prefer
  direct expression, but depart from a rule when following it would harm meaning.
- [PEP 257](https://peps.python.org/pep-0257/): Python docstring structure and content.

The linked works retain their own licenses and copyrights. This synthesis is not
an endorsement, complete reproduction, or claim of full Google house-style

Language-specific sources are linked in
[Source documentation](source-documentation.md). Review those references against
the receiving project's toolchain before adopting a new syntax. Do not require
network access for routine writing or deterministic repository checks.
