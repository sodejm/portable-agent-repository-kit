# Licensing

PARK requires an explicit license choice during project configuration:

- `mit`: permissive and concise;
- `apache-2.0`: permissive with an express patent grant and notice obligations;
- `none`: no project license file is created.

`none` does not mean public domain or unrestricted use. Without a license, default
copyright rules generally apply. Choose based on ownership, contribution model,
dependencies, distribution, patent concerns, and organizational policy. This
template is not legal advice.

PARK itself is released under the Apache License 2.0. That choice applies to the
template repository, not automatically to projects created from it. Generated
projects must still choose `mit`, `apache-2.0`, or `none` explicitly.
